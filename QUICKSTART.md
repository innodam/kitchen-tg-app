# Быстрый старт

## 1. Установка зависимостей

```bash
cd kitchen-tg-app
npm install
```

## 2. Настройка окружения

Создайте файл `.env` в корне проекта:

```bash
PORT=3000
TELEGRAM_BOT_TOKEN=your_bot_token_here
DATABASE_PATH=./kitchen.db
UPLOAD_DIR=./uploads
```

**Примечание:** `TELEGRAM_BOT_TOKEN` опционален для локального тестирования, но необходим для работы в Telegram.

## 3. Запуск сервера

```bash
npm start
```

Или в режиме разработки с автоперезагрузкой:

```bash
npm run dev
```

Сервер запустится на `http://localhost:3000`

## 4. Добавление тестовых данных (опционально)

```bash
node seed.js
```

Это добавит:
- 3 тестовых сотрудника
- 2 технологические карты

## 5. Тестирование

Откройте в браузере: `http://localhost:3000`

Вы сможете:
- Просматривать график работы
- Рассчитывать зарплату
- Просматривать и создавать технологические карты

## 6. Настройка Telegram Mini App

### Вариант 1: Через BotFather

1. Создайте бота через [@BotFather](https://t.me/BotFather):
   ```
   /newbot
   ```

2. Создайте Mini App:
   ```
   /newapp
   ```
   - Выберите вашего бота
   - Укажите название и описание
   - URL: `https://yourdomain.com` (или используйте ngrok для локального тестирования)

3. Настройте кнопку меню:
   ```
   /setmenubutton
   ```
   - Выберите бота
   - Текст: "Кухня"
   - URL: `https://yourdomain.com`

### Вариант 2: Локальное тестирование с ngrok

1. Установите ngrok: https://ngrok.com/

2. Запустите туннель:
   ```bash
   ngrok http 3000
   ```

3. Используйте полученный HTTPS URL в настройках Mini App

## 7. Добавление сотрудников

Через API или напрямую в базе данных:

```sql
INSERT INTO employees (telegram_id, name, hourly_rate) 
VALUES ('123456789', 'Имя Сотрудника', 500);
```

Или через интерфейс приложения (если добавить форму создания сотрудников).

## Структура базы данных

База данных создается автоматически при первом запуске. Файл: `kitchen.db`

### Таблицы:
- `employees` - сотрудники
- `kitchen_zones` - зоны кухни (создаются автоматически)
- `work_schedule` - график работы
- `recipe_cards` - технологические карты

## API для тестирования

### Получить всех сотрудников
```bash
curl http://localhost:3000/api/employees
```

### Добавить смену
```bash
curl -X POST http://localhost:3000/api/schedule \
  -H "Content-Type: application/json" \
  -d '{
    "employee_id": 1,
    "zone_id": 1,
    "date": "2024-01-15",
    "start_time": "09:00",
    "end_time": "18:00"
  }'
```

### Получить технологические карты
```bash
curl http://localhost:3000/api/recipes
```

## Решение проблем

### База данных не создается
- Убедитесь, что у приложения есть права на запись в директорию проекта

### Фото не загружаются
- Проверьте, что директория `uploads` создана и доступна для записи

### Ошибки CORS
- Убедитесь, что сервер запущен и доступен по указанному URL
