# Telegram Mini App для сотрудников кухни

Приложение для управления графиком работы, расчета зарплаты и просмотра технологических карт блюд.

## Функционал

### 1. График работы
- Просмотр графика работы сотрудников
- Фильтрация по зонам кухни и датам
- Добавление новых смен с указанием:
  - Сотрудника
  - Зоны кухни
  - Даты и времени работы
- Автоматический подсчет отработанных часов

### 2. Расчет зарплаты
- Выбор сотрудника и периода
- Автоматический расчет зарплаты на основе:
  - Отработанных часов
  - Часового оклада сотрудника

### 3. Технологические карты
- Просмотр списка всех технологических карт
- Создание новых карт с:
  - Названием блюда
  - Описанием
  - Списком ингредиентов
  - Пошаговыми инструкциями приготовления
  - Фотографией блюда
- Редактирование и удаление карт

## Установка и запуск

### Требования
- Node.js 14+ 
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Настройка
1. Скопируйте `.env.example` в `.env`
2. Заполните необходимые параметры:
   - `PORT` - порт сервера (по умолчанию 3000)
   - `TELEGRAM_BOT_TOKEN` - токен вашего Telegram бота
   - `DATABASE_PATH` - путь к файлу базы данных
   - `UPLOAD_DIR` - директория для загрузки фото

### Запуск
```bash
# Режим разработки (с автоперезагрузкой)
npm run dev

# Продакшн режим
npm start
```

## Настройка Telegram бота

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота
3. Настройте Web App:
   ```
   /newapp
   ```
   Укажите:
   - Название приложения
   - Описание
   - URL вашего приложения (например: `https://yourdomain.com`)
   - Иконку (опционально)

4. Добавьте кнопку меню в боте:
   ```
   /setmenubutton
   ```
   Выберите бота и укажите:
   - Текст кнопки: "Кухня"
   - URL: `https://yourdomain.com`

## API Endpoints

### Сотрудники
- `GET /api/employees` - список сотрудников
- `POST /api/employees` - добавление сотрудника

### Зоны кухни
- `GET /api/zones` - список зон

### График работы
- `GET /api/schedule` - список смен (с фильтрами)
- `POST /api/schedule` - добавление смены

### Зарплата
- `GET /api/salary` - расчет зарплаты (требует employee_id, start_date, end_date)

### Технологические карты
- `GET /api/recipes` - список всех карт
- `GET /api/recipes/:id` - получение карты по ID
- `POST /api/recipes` - создание карты (с фото)
- `PUT /api/recipes/:id` - обновление карты
- `DELETE /api/recipes/:id` - удаление карты

## База данных

Приложение использует SQLite. База данных создается автоматически при первом запуске.

### Таблицы:
- `employees` - сотрудники
- `kitchen_zones` - зоны кухни
- `work_schedule` - график работы
- `recipe_cards` - технологические карты

## Развертывание

Для продакшн развертывания рекомендуется:
1. Использовать PostgreSQL вместо SQLite
2. Настроить HTTPS
3. Использовать процесс-менеджер (PM2)
4. Настроить обратный прокси (Nginx)
