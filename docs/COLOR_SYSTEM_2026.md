# Цветовая система приложения «Кухня» (2026)

Тренды: тёплая нейтральная база, earthy-оттенки (sage, olive, terracotta), мягкие пастели, контролируемые акценты для CTA, полноценная тёмная тема. Цвета подобраны с учётом WCAG AA и условий кухни (влажность, слабое освещение, быстрый взгляд).

## 2. ThemeData (CSS-переменные)

В проекте используется не Flutter, а веб (HTML/CSS). Эквивалент ThemeData — набор CSS-переменных в `:root` и `[data-theme="dark"]`.

```css
/* Light theme (default) */
:root {
    --color-primary: #B85C38;
    --color-primary-variant: #9A4A2A;
    --color-secondary: #6B8E6B;
    --color-secondary-variant: #A8C5B5;
    --color-background: #F5F2ED;
    --color-surface: #EDE9E3;
    --color-surface-elevated: #E5E0D8;
    --color-error: #B53D3D;
    --color-warning: #C4892E;
    --color-success: #4A7C59;
    --color-text-primary: #2C2A26;
    --color-text-secondary: #5C5954;
    --color-text-tertiary: #8A8681;
    --color-outline: #C9C4BC;
    --color-accent-pastel: #D4C4B0;
}

/* Dark theme */
[data-theme="dark"] {
    --color-primary: #E07D5A;
    --color-primary-variant: #F09A7A;
    --color-secondary: #7FA07F;
    --color-secondary-variant: #5A7268;
    --color-background: #1C1B18;
    --color-surface: #282620;
    --color-surface-elevated: #322F2A;
    --color-error: #E07070;
    --color-warning: #D4A24A;
    --color-success: #6B9B7A;
    --color-text-primary: #E8E6E1;
    --color-text-secondary: #A8A6A0;
    --color-text-tertiary: #7A7874;
    --color-outline: #3D3B36;
    --color-accent-pastel: #4A4238;
}
```

## 3. Рекомендации по использованию в интерфейсе кухни

1. **Фон и поверхности**
   - Основной фон — всегда тёплый нейтрал (`background`), не чистый белый/чёрный.
   - Карточки смен, календарь, модалки — `surface`; нав-бар, плавающие панели — `surface-elevated`.
   - Так снижается усталость глаз при частом взгляде на экран и при плохом освещении.

2. **Кнопки и CTA**
   - Главное действие («Сохранить», «Добавить смены») — `primary` (terracotta). Хорошо заметно и не режет глаз.
   - Второстепенные действия — `secondary` (sage) или контурная кнопка с `outline`.
   - Опасные действия (удаление) — `error`; только для явно деструктивных операций.

3. **Зоны кухни в календаре**
   - Использовать оттенки `secondary` и `secondary-variant` (sage/olive) для разных зон, плюс при необходимости `accent-pastel` (terracotta пастель) для одной из зон.
   - Избегать чисто синих/фиолетовых тонов: в условиях кухни earthy-палитра читается стабильнее.

4. **Текст**
   - Заголовки и основной контент — `text-primary`.
   - Подписи к полям, время в ячейках, «часов» — `text-secondary`.
   - Неактивные элементы — `text-tertiary`.
   - На кнопках primary — белый или очень светлый текст для контраста ≥ 4.5:1.

5. **Обратная связь**
   - Успешное сохранение / «Добавлено» — `success`.
   - Предупреждение (например, «Заполните поля») — `warning`.
   - Ошибка сети / валидации / удаление — `error`.

6. **Тёмная тема**
   - Включение по системной настройке или переключателю; класс/атрибут на `html` или `body`: `data-theme="dark"`.
   - В тёмной теме не инвертировать светлую: использовать заданные тёмные `background`, `surface`, `surface-elevated` и осветлённые `primary`/`secondary`/семантические цвета.

7. **Контраст и читаемость**
   - Все комбинации текст/фон проверены на соответствие WCAG AA (нормальный текст ≥ 4.5:1, крупный ≥ 3:1).
   - На кухне предпочтительнее чуть увеличенный размер шрифта для ключевых данных (время смены, имя сотрудника) и достаточная толщина шрифта (medium/semibold для цифр и времени).

8. **Влажность и грязь**
   - Избегать чисто белых и глянцевых поверхностей в UI: тёплые нейтралы и матовые эффекты (без сильного блика) снижают видимость отпечатков и отвлечение.

Эти правила можно зафиксировать в гайде по компонентам и передать в реализацию (например, в `styles.css` и компоненты).
